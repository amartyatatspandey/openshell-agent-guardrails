02 — Purpose of this deck

This deck exists to show you three things.

Not just that the demo works, but how I think about the problem and how I build when the tool is new.
01Understanding

I understand where the gap is.

Admission control decides what gets deployed. A running agent acts after that. I can show where each of its actions is stopped, and by what.

  • Runtime is the layer admission never sees
  • OpenShell's trust model, part by part
  • Each control mapped to an AIControls plane
EVIDENCE · SLIDES 04 – 07, 09
02Robust approach

I build it like it has to hold.

Deny by default, and evidence that comes from the runtime, never from my own script.

  • Graded from OpenShell's OCSF log
  • Pinned versions, preflight before anything runs
  • Fake data, reserved destinations only
  • Honest about what is single-box
EVIDENCE · SLIDES 08, 10 – 11, 14 – 15
03Demonstration

It works, and you can check it.

One command creates the sandbox, runs the attempts, reads the log and grades it.

  • make verify → 10 PASS / 0 FAIL
  • Exits non-zero if one control fails to block
  • Re-run from a fresh clone before sending
  • Working bonus: Kyverno decides, OpenShell enforces
