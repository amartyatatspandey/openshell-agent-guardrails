20 — Scope, and how to run it

Precise about what it is, and what it isn't

What this is not
  • Not a fleet. One gateway, one Docker host, one sandbox.
  • Not AIControls. It's the runtime evidence a fleet product would want to collect.
  • Not production-grade OpenShell. v0.1.3 is alpha, so it's pinned.
  • Not the cost domain. Spend and quotas aren't measured here.
  • Not response-side. Injection carried in a tool's response isn't inspected.
  • Not a retention system. The signed evidence stays on this machine.
