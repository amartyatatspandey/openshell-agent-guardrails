Evidence you can check after the fact

.out/evidence/evidence-<UTC>.json
  • OpenShell, prover and Docker versions, and the image ID
  • SHA-256 of the policy, both signatures, the boundary, the expectations table, the probes, the grader
  • The policy-gate output and the prover's JSON
  • Every graded row with the exact line that proved it
  • Signed with the review key, namespace openshell-evidence
h0 = sha256("openshell-guardrails-evidence-v1")
hi = sha256(hi−1 ‖ id ‖ result ‖ evidence line)
change, drop or reorder a row → every later hash changes
$ make evidence 12 PASS, 0 FAIL (12 rows) evidence: 12 PASS, 0 FAIL (12 rows), chain head 786b0cff38b53d79… signed: .out/evidence/evidence-20261014T061039Z.json.sig $ make evidence-verify signature: valid (openshell-policy-review) chain: intact, 12 rows, 12 PASS / 0 FAIL files: unchanged since the run $ # flip one row's result in a copy of the bundle signature: INVALID (the bundle changed after it was signed) chain: BROKEN at row 3 (egress-default-deny)
Scope
This is tamper-evident evidence, not a retention system: the bundle stays on this machine. In a fleet it is the record you would ship to a SIEM, and the one an auditor could re-check without trusting the person who ran it.
