19 — Honesty · what the docs didn't tell me

What I got wrong, and how I found out

01 · OPENSHELL ON MACOS

Sandbox creation just failed

SawStartup configuration fetch failed, with no doc explaining it.
CauseDocker Desktop host networking was off, so the supervisor couldn't reach the gateway.
FixPreflight reads HostNetworkingEnabled and says how to fix it.
02 · MY OWN PREFLIGHT

It rejected a correct install

SawA fresh clone failed on the version check.
CauseThe CLI prints 0.1.3. I matched v0.1.3.
FixFixed the match. Now I always test the handover, not just the build.
03 · A LOG LINE I DIDN'T TRUST

A draft invented a reason string

SawA draft doc said metadata denials read "always-blocked address".
CauseWritten from assumption. The real line says transparent_tcp_policy_denied.
FixEvery pattern is checked against captured output, and the fixtures are real.
04 · KYVERNO AUTHZ

It loaded zero policies, silently

SawNo policy decisions were being made, and there was no error.
Causev0.4.0 wants policies.kyverno.io/v1alpha1. The current docs show v1.
FixPinned the apiVersion and confirmed the DENY in OpenShell's log.
05 · KYVERNO AUTHZ

An allow overrode a deny

SawWith two policies loaded, every MCP call passed, but each policy alone was correct.
CauseThe GitHub rule's explicit Allowed() decided requests it was never meant for.
FixmatchConditions per policy, then re-proved every case live.
06 · LIFECYCLE

The guard died while registered

SawThe process exited with the shell that started it.
CauseThe gateway refuses to start if a registered middleware is down.
FixBuilt binary + nohup. Stop unregisters and restores the config exactly.
Pattern
When the docs ran out, I went to the source and to real output, and fixed the tooling so the next person doesn't hit the same wall.
