05 — What I had to learn · OpenShell v0.1.3

OpenShell in four parts, and who is trusted

Trusted · control plane

Gateway

Holds sandbox policy, providers (credentials) and the audit stream. Creates sandboxes through the compute driver.

https://localhost:17670
Trusted · per sandbox

Supervisor

Every connection the agent makes goes through its proxy. It evaluates policy, injects credentials, and writes OCSF events.

decides + enforces + logs
Untrusted · the agent

Sandbox

The agent's process. It sees a Landlock filesystem view, runs as non-root, and holds only credential placeholders.

uid 1000 · Landlock · placeholders
Infrastructure

Compute driver

Docker, Podman, Kubernetes or a VM. Here, Docker Desktop on macOS, which needs host networking on.

Docker ≥ 28 · host networking
